# Глосарій Tamga

## Українські криптографічні стандарти

| Термін | Розшифровка | Контекст у Tamga |
| --- | --- | --- |
| ДСТУ 4145-2002 | Український стандарт електронного підпису на еліптичних кривих | Цільовий алгоритм підпису. |
| ДСТУ 7564:2014 | Купина, українська хеш-функція | Використовується у криптографічних сценаріях через `cryptonite`. |
| ДСТУ 7624:2014 | Калина, український блоковий шифр | Цільовий стандарт симетричної криптографії для подальшого розвитку. |
| ГОСТ 34.310-95 | Цифровий підпис пострадянського стандарту | Може підтримуватись `cryptonite`, але не є основною метою Tamga. |
| ГОСТ 34.311-95 | Хеш-функція пострадянського стандарту | Допоміжна сумісність на рівні криптобібліотеки. |

## PKI і підписи

| Термін | Значення |
| --- | --- |
| ЕЦП | Електронний цифровий підпис. |
| PKI | Інфраструктура відкритих ключів: сертифікати, ключі, довіра, відкликання. |
| X.509 | Стандарт сертифікатів відкритих ключів. |
| CMS | Cryptographic Message Syntax, базовий контейнер для підписаних даних. |
| CAdES | Advanced Electronic Signatures на базі CMS. |
| CAdES-BES | Базовий рівень CAdES без обов'язкового timestamp token. |
| CAdES-T | CAdES із RFC 3161 timestamp token. |
| ASiC | ZIP-контейнер для документа, підпису і службових файлів. |
| ASiC-S | Простий ASiC-контейнер для одного документа. |
| ASiC-E | Розширений ASiC-контейнер для складніших сценаріїв. |

## Формати ключів і серіалізації

| Термін | Значення |
| --- | --- |
| ASN.1 | Нотація опису структур даних для криптографічних стандартів. |
| DER | Бінарне кодування ASN.1. |
| BER | Базове, менш суворе кодування ASN.1. |
| PEM | Base64-обгортка над DER з текстовими заголовками. |
| PKCS#12 / PFX / P12 | Контейнер приватного ключа і сертифіката. |
| PKCS#8 | Формат приватного ключа без обов'язкового сертифіката. |
| JKS | Java KeyStore. |

## Мережеві протоколи PKI

| Термін | Значення | Поточний стан |
| --- | --- | --- |
| TSP | Time-Stamp Protocol, RFC 3161 | Використовується для timestamp-сценаріїв; production validation ще потребує розширення. |
| TSA | Time-Stamp Authority | Зовнішній сервіс, який видає timestamp token. |
| OCSP | Online Certificate Status Protocol | Налаштування є, повна revocation policy не завершена. |
| CRL | Certificate Revocation List | Повна перевірка відкликання не завершена. |
| LDAP | Lightweight Directory Access Protocol | Наступна фаза. |
| CMP | Certificate Management Protocol | Наступна фаза. |

## Артефакти Tamga

| Термін | Значення |
| --- | --- |
| `tamga-lib` | Shared library з бізнес-логікою для розробників; NativeAPI і CLI лінкують той самий core-код статично. |
| `tamga-core-static` | Внутрішня static library для single-file `Tamga.dll` і `tamga-cli.exe`. |
| `tamga-nativeapi` | CMake target для NativeAPI DLL `Tamga.dll`. |
| `tamga-cli` | Консольна утиліта для сценаріїв без 1С. |
| `tamga-tests` | CTest executable з regression/integration перевірками. |
| NativeAPI | Механізм 1С для завантаження нативних компонент. |
| `IComponentBase` | Базовий C++ інтерфейс NativeAPI 1С. |
| `tVariant` | Універсальний тип параметрів NativeAPI. |
| `WCHAR_T` | Тип символу рядка NativeAPI 1С. |

## Технічні терміни

| Термін | Значення |
| --- | --- |
| baseline | Поточний зафіксований стан, який збирається і проходить наявні тести. |
| vendor snapshot | Копія сторонньої бібліотеки у `vendor/`. |
| patch queue | Набір patch-файлів у `patches/`, який документує локальні відхилення від vendor upstream. |
| smoke test | Швидка перевірка експорту, runtime-залежностей або запуску CLI. |
| trust validation | Перевірка довіри до сертифіката через trust-store, chain policy і revocation. |
| crypto integrity | Перевірка, що підпис криптографічно відповідає даним. |
